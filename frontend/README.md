# Swave frontend

React + Vite app for the Swave music discovery UI.

## Run

```bash
npm install
npm run dev
```

Opens **http://127.0.0.1:8080** by default (`vite.config.ts`).

Backend must run at **http://127.0.0.1:8000** (`frontend/src/api/client.ts`).

## Scripts

- `npm run dev` — local dev server
- `npm run build` — production build
- `npm run lint` — ESLint
